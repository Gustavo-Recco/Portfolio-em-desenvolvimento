# Portfólio - Gustavo Fernandes Recco

Portfólio profissional de Gustavo Fernandes Recco, estudante de Tecnologia da Informação e Comunicação na UFSC Araranguá, com interesse em inteligência artificial, robótica e direção criativa.

> **Status: em desenvolvimento.** O conteúdo e o visual ainda estão sendo ajustados.

O endereço do site está no campo **About** do repositório.

## Seções do site
- **Quem sou:** apresentação pessoal.
- **Objetivo profissional:** áreas de interesse e caminhos que estou considerando.
- **Formação e experiências:** graduação e experiências profissionais.
- **Competências:** o que já tenho e o que estou desenvolvendo.
- **Projetos:** trabalhos acadêmicos e pessoais.
- **Contato:** LinkedIn e GitHub.

## Projetos apresentados
- **Lingu:** assistente de estudos de idiomas em Python (Sistemas Multimídia). Código em [github.com/Gustavo-Recco/Lingu](https://github.com/Gustavo-Recco/Lingu).
- **Site da Fioart's Aviamentos (2024):** projeto front-end de uma loja, hoje encerrado.
- **Plataforma de conversação em inglês com IA:** projeto de Engenharia de Software I.
- **Calculadora em Java:** pilhas genéricas sobre lista encadeada.

## Tecnologias
- HTML5
- CSS3 (grid, flexbox e variáveis CSS)
- JavaScript (animação em canvas, sem bibliotecas)
- Google Fonts (Chakra Petch e Figtree)

Não há dependências nem etapa de build.

## Estrutura
```
index.html   conteúdo da página
style.css    estilos
script.js    animação da esfera no topo
```

## Como visualizar no computador
1. Baixe o repositório (Code > Download ZIP) e extraia os arquivos.
2. Abra o `index.html` no navegador.

Para carregar as fontes, é preciso estar conectado à internet. Sem conexão, o site usa fontes do sistema.

## Publicação
O site é publicado com o GitHub Pages (Settings > Pages, branch `main`, pasta `/ (root)`).
